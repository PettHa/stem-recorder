## Default Permission

Default permissions for the stem-recorder plugin

#### This default permission set includes the following:

- `allow-list-devices`
- `allow-start-monitor`
- `allow-stop-monitor`
- `allow-start-record`
- `allow-stop-record`
- `allow-get-stats`
- `allow-verify-wav`
